Тип расчета и параметры системы

&nbsp;   calculationMethod - задает используемый метод расчета (по умолчанию USPEX — алгоритм эволюционного предсказания)

&nbsp;   calculationType - определяет тип расчета с помощью трех индексов (размерность, молекулярность, вариативность состава) и иногда спиновой опции (например, 300 — объемные кристаллы фиксированного состава, 301 — переменного состава)

&nbsp;   optType  — указывает свойство или свойства для оптимизации (по умолчанию это энтальпия и объем, но можно максимизировать плотность, ширину запрещенной зоны и др.)

&nbsp;   atomType - — идентификаторы для каждого типа атомов (можно использовать порядковые номера из таблицы Менделеева, символы или полные названия элементов)

&nbsp;   numSpecies - — задает количество атомов, молекул или композиционных блоков каждого типа в ячейке

&nbsp;   ExternalPressure - — внешнее давление в ГПа, при котором ведется поиск стабильных структур

&nbsp;   valences — валентности каждого типа атомов; используются в основном для вычисления параметров жесткости связей и генерации фононов

&nbsp;   goodBonds — квадратная матрица минимальных валентностей межатомных контактов, которые расцениваются алгоритмом как существенные связи

&nbsp;   checkConnectivity — включает (1) или выключает (0) вычисление жесткости и критерии проверки связности структуры

    fitLimit — пороговое значение оптимизируемого свойства (приспособленности), при достижении которого расчет успешно останавливается



Настройки популяции и селекции:

&nbsp;   populationSize — количество структур (особей) в одном поколении.

&nbsp;   initialPopSize — количество структур в самом первом начальном поколении (полезно указывать больше, чем populationSize, особенно для систем с переменным составом).

&nbsp;   numGenerations — максимальное разрешенное количество поколений в расчете.

&nbsp;   stopCrit — критерий ранней остановки (например, если лучшая структура не меняется на протяжении заданного числа поколений).

&nbsp;   bestFrac — доля лучших структур текущего поколения, которые станут родителями для создания следующего.

&nbsp;   keepBestHM — число самых лучших структур, которые гарантированно перейдут (выживут) в следующее поколение.

&nbsp;   reoptOld — определяет, нужно ли заново запускать релаксацию для выживших структур (0 — не нужно, 1 — нужно).



Структурная генерация и операторы вариации:

&nbsp;   symmetries — список номеров пространственных групп, которые разрешено использовать генератору случайных симметричных структур.

&nbsp;   splitInto — число идентичных подячеек или псевдоподячеек, на которые разбивается ячейка (используется для систем с большим числом атомов).

&nbsp;   fracGene — доля структур, создаваемых путем наследственности (скрещивания двух или более структур).

&nbsp;   fracRand — доля структур, создаваемых случайным симметричным генератором.

&nbsp;   fracTopRand — доля структур, получаемых топологическим генератором.

&nbsp;   fracPerm — доля структур, создаваемых путем перестановок атомов разных типов.

&nbsp;   fracAtomsMut — доля структур, получаемых мягкой или координатной мутацией.

&nbsp;   fracPyXTal — доля структур, получаемых через генерацию в программе PyXTal.

&nbsp;   howManySwaps — предельное количество парных атомных перестановок при применении оператора fracPerm.

&nbsp;   specificSwaps — позволяет ограничить перестановки атомов только между определенными типами химических элементов.

&nbsp;   AutoFrac — включает интеллектуальную автонастройку процентных долей операторов вариации прямо во время расчета (1 — вкл., 0 — выкл.).



Ограничения и ячейка:

&nbsp;   minVectorLength — минимально допустимая длина вектора элементарной ячейки для новых генерируемых структур.

&nbsp;   IonDistances — матрица, задающая минимально возможные межатомные расстояния для всех пар элементов; структуры с расстояниями меньше заданных отклоняются.

&nbsp;   constraint enhancement — позволяет временно ужесточить матрицу IonDistances для симметричных случайных структур.

&nbsp;   Latticevalues — позволяет задать начальный объем элементарной ячейки, известные параметры решетки (через матрицу 3x3 или длины векторов a, b, c и углы).



Настройки ab initio расчетов и запуска задач:

&nbsp;   abinitioCode — указывает, какой сторонний код используется на каждом шаге оптимизации (например, 1 - VASP, 3 - GULP, 5 - ORCA, 0 - MatterSim).

&nbsp;   KresolStart (и Kresolend) — позволяет задать постепенное увеличение разрешения сетки k-точек на различных этапах релаксации (ускоряет вычисления).

&nbsp;   vacuumSize — задает толщину вакуумного слоя (в Å), добавляемого для поверхностей, кластеров или 2D-кристаллов.

&nbsp;   numParallelCalcs — количество структурных релаксаций, выполняемых параллельно.

&nbsp;   commandExecutable — команды запуска или имена скриптов для запуска внешнего кода (например, VASP или GULP) на каждом этапе релаксации.

&nbsp;   whichCluster — определяет формат отправки задач (0 — без скриптов, 1 — локальная отправка на рабочую станцию, 2 — удаленная отправка на суперкомпьютер).

&nbsp;   remoteFolder — путь к директории на удаленном кластере (активируется, если whichCluster=2).

&nbsp;   PhaseDiagram — включает предварительную оценку стабильности фаз при различных давлениях в виде построения фазовой диаграммы.

&nbsp;   coresPerJob — число ядер процессора, выделяемых для одной отдельной задачи релаксации на локальной машине.

&nbsp;   sleepSeconds — задержка (в секундах) перед запуском следующих последовательных релаксаций.



Перезапуск расчета:

&nbsp;   pickUpGen и pickUpFolder — указывают номер поколения и номер папки (resultsX), начиная с которых алгоритм должен подхватить и продолжить уже прерванный расчет.

&nbsp;   RmaxFing — радиус обрезания (в Å) для вычисления структурного фингерпринта.

&nbsp;   deltaFing — шаг дискретизации для функции фингерпринта.

&nbsp;   sigmaFing — Гауссово уширение межатомных расстояний при расчете фингерпринта.

&nbsp;   doSpaceGroup — включает определение пространственных симметрий (используя spglib) и запись результатов в формате .CIF.

&nbsp;   SymTolerance — параметр точности (допуск), используемый утилитой при поиске симметрии.



Параметры для переменного состава (Variable-composition):

&nbsp;   firstGeneMax — количество различных случайных химических составов, используемых при инициализации первого поколения.

&nbsp;   minAt и maxAt — соответственно минимальное и максимальное количество атомов (или молекул) в примитивной ячейке.

&nbsp;   fracTrans — доля структур, получаемых оператором трансмутации (когда один атомный вид случайным образом заменяется на другой из присутствующих).

&nbsp;   howManyTrans — максимальный процент атомов внутри структуры, которые подвергнутся трансмутации.



Редко используемые команды (расширенные / для разработчиков):

&nbsp;   mutationRate — стандартное отклонение компонентов матрицы деформации при выполнении мутации решетки.

&nbsp;   mutationDegree — максимальное физическое смещение (в Å) для атомов в операторе мягкой мутации.

&nbsp;   ordering active — включает влияние параметров локального порядка на поведение операторов вариации.

&nbsp;   symmetrize — преобразует все выходящие структуры к стандартным кристаллографическим установкам.

&nbsp;   valenceElectr — количество валентных электронов для каждого типа атома (обычно встроено в код).

&nbsp;   percSliceShift — вероятность дополнительного сдвига слоев при операторе наследственности.

&nbsp;   maxDistHeredity — максимальное фингерпринтное косинусное расстояние между структурами для разрешения их участия в скрещивании.

&nbsp;   manyParents — регулирует возможность использования более чем двух родительских структур/слоев при скрещивании (полезно для гигантских систем).

&nbsp;   minSlice и maxSlice — определяют минимальную и максимальную толщину (в Å) слоев, вырезаемых из родителей при создании потомка.

&nbsp;   repeatForStatistics / stopFitness — автоматизируют запуск повторяющихся прогонов до достижения целевого значения приспособленности (для сбора алгоритмической статистики разработчиками).

&nbsp;   fixRndSeed — позволяет жестко зафиксировать "сид" генератора случайных чисел для достижения точной воспроизводимости прогона.

&nbsp;   collectForces — включает функцию агрегирования сил, позиций и тензоров напряжений из файлов VASP (напрямую в файл FORCE.mat) для последующего использования в машинном обучении.
