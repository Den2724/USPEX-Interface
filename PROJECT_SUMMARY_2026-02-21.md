# USPEX Interface: описание проекта и отчёт за 2026-02-21

## Описание проекта

`USPEX_interface` — это локальный GUI на `Streamlit` для подготовки и запуска расчётов `USPEX`, мониторинга статуса, просмотра логов и анализа результатов.

Ключевые возможности:
- настройка путей (`uspex.exe`, рабочая папка);
- выбор режима генерации входных данных (`fixed`, `single`, `variable`);
- предпросмотр и редактирование `INPUT.txt`;
- запуск/остановка расчёта и чтение live-лога;
- просмотр результатов релаксации из `Calculation/Calcfold_N_M`;
- навигация по папкам в пределах выбранного корня;
- работа с Seeds (добавление POSCAR/POSCARS, проверка структур, удаление, экспорт в `Seeds/POSCARS` перед запуском).

Основной исполняемый модуль: `app/app.py`.
